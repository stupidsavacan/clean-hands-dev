### 遊んで変わること

- **立入禁止の警告**：スーツで厨房などに入って警備に見つかると、まず歩いて来て「ここは立入禁止だ。出ていけ」と言う。
  - 出て、1秒何もしなければ終わる。服はバレない。
  - 4m以内で3秒たっても違反を続けると、「取り押さえに来る」。このときだけ捕まる。
  - 走る・しゃがむなど怪しい動きや、立入禁止ではないが服が場違いな場所（スーツで駐車場など）で警戒されたときも、警告から始まる。言葉は「おい、何をしている。ここから離れろ」。
  - 客が、すでにバレた服を見て警備に知らせても、ホテルの警戒度は上がらない（上がるのは犯罪や死体の通報だけ）。
- **警告なしで取り押さえに来るとき**：顔を知られた（白いゲージ）、犯罪を見られた（細工・銃）、`secure` 区域（ペントハウスなど）にいる。
- **検問**：
  - 大階段とマリーナの検問は、**警備員の服なら検査なしで通れる**（HITMAN と同じ）。検査しないので、消音ピストルなどを持っていても通れる。`weaponPolicy` を付けた検問だけは、その服でも止められる。
  - 検査で見つかる物を持っていると、検査を始められない。表示は「〇〇を持っていると検査で見つかる。置いてこないと通れない。」。警備は警戒しない。
  - 警備員の服や私設護衛の服で背負った短機関銃は、持っていてよい物として扱う。前は検査で違法になっていた。
  - 検査のあとに何かを拾う・置くと、通行証は無効になる。
- **一般人の通報**：怪しい人を見た一般人は、走って警備に知らせに行く。着くまでは、ほかの誰も知らない。途中で気絶させれば止まる。
  - 怪しい動きだけの通報なら、警備は確かめに来るだけで、服はバレない。
  - 給仕長など、警備でない「顔を知る人」に見破られたときも、警備に知らせ終わるまで服はバレない。
- **撃たれて生き残った警備**：撃った人を見ていれば撃ち合い。見ていなければ、撃たれた方向（撃った地点）へ捜索に行く。そのとき、今いる場所や服は分からない。
- **銃声**：屋内の大きな銃声は30mまで。1つ上下の階は半分、2階以上離れると聞こえない。壁や床を挟むとさらに半分。屋外どうしは40m（前と同じ）。消音は8m（前と同じ）。
  - 誰にも聞こえなかった銃声では、ホテルの警戒度は上がらない。
- **増援**：数（3波×4人＝12人）と装備は前と同じ。プレイヤーから見える近い出現点は避ける。倒すと短機関銃を落とす（前と同じ。今は `weapons.json` に書いた）。
  - 遊んだあとの直し（メモ「不動の増援」）：捜索が終わっても立ち止まらず、警戒度3の間は、最後に分かった場所（なければ自分の近く）の4〜14m先を次々に捜す。前は、捜索が終わるとその場（階段の途中も）で立ったままだった。
  - 2人が同じ通り道を取り合って押し合うと、どちらも止まったままになっていた（駐車場の出現点で起きた）。押し戻された分も含めて進んだ距離を見るようにし、詰まったら道を選び直す。全員に効く直し。

### 遊んだあとの直し（2026-11-02 の2回目）

- **銃を捨てる**：手に何も持っていないときに **Q** を長押しすると、構えずに銃を捨てる（長物が先、次に拳銃）。前は構えないと捨てられず、人前で構えると撃ち合いになるため、拾った短機関銃や警備の拳銃を持ったまま検問を通れなかった。
  - 検問で止められたときの表示に、捨て方を書いた（「銃はQ長押しで捨てる」「手の物はUで置く」）。致死毒は捨てられないので、「毒は捨てられない。検査のない服なら通れる」と出す。

- **階段の足**（主人公も周りの人も）：膝が150〜180°まで折れ、走ると太ももが裏返っていた。次の3つで直した。
  - 下の段に残った足は早めにつま先立ちにして、腰を下に引かない。
  - 段を上るときだけ足を持ち上げる。下りるときは持ち上げない。
  - 階段では歩幅を0.8倍にする。
  - 結果（`investigation/stairs-legs.ts`）：歩いて上るとき、膝の最大は152°から113°、100°を超える時間は46%から8%。走って上るときは180°から134°（平らな所を走るときは118°）。

仕様は M5実装ガイドの「M5 · DETECTION」と detection 関連データ。顔を知る人（M4）に加えて、目撃者・持ち物・監視カメラ・溶け込みの4つを入れた。データは `src/data/detection.json`、仕組みは `src/detection.ts`、表示は `src/detection-view.ts`。

- **目撃者**：客やスタッフが犯行（銃を出している、気絶・殺害）や殺された死体を見ると、頭上に赤い「！」が出て、いちばん近い警備員へ走る。着いたときに初めてホテル警戒度が1上がり、警備員がその場所へ向かう。途中で気絶させれば通報されない。警備員が自分で見た場合は従来どおり無線で即通報。撃ち合いの最中に目撃した客は通報せず逃げる。これまで客が見ても即座に無線が飛んでいたのをやめた（無線は警備員だけ）。
- **持ち物**：違法・疑わしい・普通の3種。疑わしい物（スパナ・ワインボトル・モップ・カメラ）は決まった服なら持っていてよく、それ以外の服だと警戒が溜まる。違法な物（銃を出している等）を見られると顔を知る人の警戒が2倍速。Eで拾う（持っている物とは入れ替え）、Uで置く。左下の持ち物欄は服に合わせて色分け（赤＝違法、黄＝この服では疑わしい、白＝問題なし）。マップに5個配置（搬入口と洗濯室のスパナ、バーのボトル、サービス通路のモップ、テラスのカメラ）。身体検査では手の物も見られる。
