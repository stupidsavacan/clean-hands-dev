# CLEAN HANDS のホテルと HITMAN のマップの比較：つくりの違い

- 作成：2026-11-01（Claude）
- 問い：「マップの構造が、そもそも悪いのではないか」
- 方法
  - **HITMAN の側**：開発者の講演と記事、攻略情報から、マップの作り方の考え方を集めました（出典は最後）。HITMAN のマップの実際の寸法・人数は公式の数字がないので、ファンの数えた値は「参考」としてだけ載せます。
  - **CLEAN HANDS の側**：ホテルのデータを、同じ物差しで測りました。スクリプトは `investigation\map-topology.ts` です。
    - 実行：`app` で `node --experimental-strip-types --no-warnings ../investigation/map-topology.ts`
    - 区域（`hotel.json` の `zones`。区域のない歩ける地面は「外」）ごとに、ナビの格子（0.5m）で隣の区域とつながっている出入り口を数えます。
  - 測ったのは 2026-11-01 02:26 時点のデータです。Codex が修正の依頼（プレイテスト2回目）を進めている途中ですが、出入り口のつながりは変わっていません。

## 結論

**あなたの見立ては、かなり当たっています。** いまのホテルは、HITMAN のマップの作り方の基本と、逆の形をしています。

1. **すべての部屋が、外の一続きの地面にぶら下がっている。** 部屋と部屋が直接つながっていません。
2. **大事な場所が、行き止まりで、入口が1つしかない。** 地下セラー、バーの裏、桟橋・マリーナ、Bの客室、バルコニーの5か所です。そこに見張りや検問が1人いるだけで、道が完全にふさがります。
3. **スタッフ用の裏の通路が、つながっていない。** 厨房・ランドリー・警備室は、それぞれ外にしか出入り口がありません。服を変えても、新しい道は開けません。
4. **上下の移動が、階段4本だけ。** はしご・雨どい・窓・縁がありません。
5. **部屋の中が、ただの四角い箱。** 中に区切りや物陰が少ないので、隠れる・隠す・見られない場所が足りません。

プレイテストで出た不具合の多くは、この形から来ています。
- A1：セラーの入口の前に、給仕長が立っている
- C5：バーの裏で、服の置き場所が丸見え
- C3：屋上に隠し場所がない
- 検問：線をよけて通る道がない

一方で、次のところは HITMAN と同じ方向で、悪くありません。
- 外の地面は輪になっていて、回り道ができる
- 4つの階がある
- 標的がホテル中を移動する

## 1. HITMAN のマップの作り方（資料から）

| 考え方 | 中身 | 出典 |
|---|---|---|
| **スイスチーズ** | マップに穴（つながり）をたくさん空ける。どの穴に入っても目的地へ行ける。行き止まりや引き返しを減らし、いつも別の進み方がある | クリエイティブ・ディレクター Christian Elverdam（Sapienza について） |
| **かたつむり（らせん）** | 層が自分の周りを巻くように重なり、坂や階段でつながる。行き止まりにぶつからず進み続けられるので、実際の面積より広く感じる。北海道では、らせんを下りながら奥の施設へ近づいていく | リード・レベルデザイナー Torbjørn Christensen |
| **社会的な空間** | 空間を、公共（誰でも入れる）と私的（入る人と振る舞いに決まりがある）に分ける。さらに6種類（誰でも入れる公共、目的のある公共、決まりの強い公共、私的、職業の場、個人の場）に分ける。空間の決まりは、その場の人と作りで、遊ぶ人に伝わる | レベルデザイナー Mette Podenphant Andersen（GDC 2019） |
| **自由な場所の中での案内** | 自由に動けるマップの中で、機会（Opportunities／Mission Stories）を使って、遊ぶ人を一つの筋へ案内する | Andersen・Mikkelsen（GDC 2016） |
| **部品の組み合わせ** | 1つの大きなマップを作り込むのではなく、使い回せる部品の組み合わせで作る作り方に変えた | Marinus Rørbech（GDC） |

### 例：パリ（The Showstopper）の宮殿

- **階**：地上、1階、2階、屋根裏、地下と、隣の庭。開発者は「宮殿に忍び込むなら」と考え、複数の階、地下、屋根裏、正面と裏の入口、隣の庭を用意しました。
- **上下の移動**：小さい階段、大きい階段、2階と屋根裏のあいだのはしご。雨どいを登って2階と屋根裏へ行けます。
- **検問**：正面に身体検査があります。地下や開いた窓など、検問を通らない入り方もあります。
- **区域の数**：ファンが数えた区域の数は、パリ 39、サピエンツァ 47、マイアミ 48 です（公式の数字ではありません）。

- **外の地面が中心です。** 外の地面だけで、14区域と26か所の出入り口でつながっています。

### 2-2. HITMAN の考え方と並べると

| 考え方 | HITMAN | ホテル |
|---|---|---|
| スイスチーズ（入口が多い、行き止まりが少ない） | 大事な場所ほど、複数の入り方がある | **行き止まり5か所。うち4か所がチャンスの舞台**（A1・A2のセラー、C5のバーの裏、A1・A5・C2の桟橋、C1のバルコニー。残りはBの客室）。入口が1つなので、そこに見張りか検問がいると、道は1本だけになる |
| かたつむり（層が巻いて、内側へ向かう） | 層が巻き、坂と階段で層がつながる | 層の形がない。部屋は、外の地面に「数珠のように」ぶら下がっているだけ。投資家の場所は、客室廊下 → ヘリポート → ペントハウス → バルコニーの一本道 |
| 表と裏の動線 | 職員の服で、表とは別の道が開ける | 裏の動線がない。厨房・ランドリー・警備室は外にしか出入り口がなく、互いにつながっていない。スタッフの服でできるのは、外から見えている同じ扉を通ることだけ |
| 上下の移動 | 階段のほかに、はしご・雨どい・窓 | 階段4本だけ。1F↔2F は2本（大階段は検問、裏の階段はスタッフ区域）、2F↔RF は1本、1F↔B1 は1本 |
| 社会的な空間 | 6種類。決まりは、その場の人と作りで伝わる | 4種類（公共・スタッフ・警備・外部）。区域の決まりが、そこで働く人と合っていない（漁師の服で、漁師の事務所に入れなかった） |
| 部屋の中 | 部屋の中に部屋、物陰、家具の配置で視線が切れる | 21室とも四角い箱。厨房は 24m × 16m の一室。隠し場所は21個、プレイヤーが隠れる場所は0 |
| 広さと人 | （参考）区域の数 39〜48。人は1マップに数百人（ファンの数え。群衆を含む） | 区域の数 26。地上 約9,600㎡ のうち、屋内の部屋は全階合わせて約3,760㎡。搬入口（約1,110㎡）や駐車場（約690㎡）など、人の少ない広い屋外が多い。人は120人で、92人は動かない |
| 標的の動き | 標的は、私的な場所と公共の場所を行き来する | 同じ。ワイン商はバー → テラス → 桟橋 → プール → 地下セラー → バー。投資家はペントハウス → バルコニー → 浜辺 → ヘリポート。**ここは良い** |

## 3. 不具合とマップの形の関係

| プレイテストの不具合 | マップの形の原因 |
|---|---|
| A1：給仕長に見抜かれる | セラーの入口が1つ（バーから）。そのすぐ前が給仕長の持ち場で、ほかの入り方がない |
| C5：服の置き場所が丸見え | バーの裏は浜辺にしか開いていない行き止まり。正面に店員が立つ |
| C3：パイロットを隠せない | 屋上は、ペントハウスまでの一本道で、中に区切りがない |
| 検問：通れない・隙間 | 大階段が、2階への表の道のただ一つ。マリーナの検問は、桟橋へのただ一つの入口（事務所の中） |
| A4・B4：静かに倒せない | 外の広い場所に人が立っていて、物陰も区切りもない |

一つの場所への入口が1つで、中に区切りがないと、決め打ちの手順で調整するしかなくなります。決め打ちの手順は、少しずれると通れなくなります。

## 4. 進め方の選択肢

### 案1：いまのホテルを、つながりから作り直す

- 先に、紙の上で「区域と出入り口のグラフ」を設計してから、座標を書きます。
- 設計の決まりの例（`map-topology.ts` で毎回確かめる）
  - チャンスの舞台になる区域は、出入り口が2つ以上。少なくとも1つは、別の手段（服・道具・上下の移動）で入れる
  - スタッフ区域は、裏でつながる（表に出ずに、厨房 → 裏通路 → ランドリー → 警備室へ行ける）
  - 階のあいだのつながりは、どの2階のあいだにも2本以上。種類を変える（表の階段、裏の階段、はしご・雨どい）
  - 大きな部屋は区切る（厨房なら、調理場・洗い場・冷蔵庫・食料庫など）
- 標的・チャンス・予定・点数は、そのまま使えます。座標は、ほぼ全部書き直しになります。
- 規模：大。ただし、今の仕組み（AI・服・仕掛け）はそのまま使えます。

### 案2：小さな新しいマップで、作り方を先に試す

- あなたの「パーティー会場」の案を、この作り方の試作の場にします。
  - たとえば、館一軒（3〜4階、表と裏の動線、屋根裏と地下、はしご・窓）と、パーティー
  - 標的は1人で十分です。
- スイスチーズとかたつむりの形が、このゲームの仕組み（服・検問・顔を知る人・見張り）と組み合わさって、本当に面白くなるかを、プレイテストの道具で確かめます。
- 面白ければ、その作り方で、ホテルを案1で作り直します。
- 規模：中。

### どちらでも必要なこと

- **上下・横の「抜け道」の仕組み**：はしご・雨どい・窓・縁を、まず「Eを長押しすると、決まった2点のあいだを移動する」つなぎとして作ります。登る動きのモーションも要ります。NPCもそのつなぎを使えるかどうかは、決める必要があります。
- **マップの自動点検**：上の決まりと、構造監査の段階1（検問・服と区域・ゴーストで歩けるか）を、テストにします。
- **作る道具**：座標を手で書くやり方では、区域が増えるほど食い違います。グラフを先に書き、点検してから座標にする手順にします。必要なら、区域と出入り口を描いて確かめる簡単な画面も作ります。

### おすすめ

**案2から始めるのがよいと思います。**
- ホテルを作り直すのは大仕事です。作り方が合っているかを、小さく確かめてからのほうが安全です。
- パーティー会場の案と、目的が重なります。
- ホテルのほうは、今の修正（Codex に依頼中）で、遊べる状態を保っておけます。

## 5. 決めてほしいこと

1. 案1（ホテルを作り直す）と案2（小さな試作から）のどちらにするか
2. 案2なら、パーティー会場を試作の場にしてよいか。広さ・階数・標的の数
3. はしご・窓などの抜け道を、NPC も使うか（使うと、見張りの動きが複雑になる）
