## 1. 群衆の見た目（いちばん大事）

メモ1の画面で、次のことが起きています。

- 全員が同じ姿勢をしている。腕を前に出した形。
- 服が2種類しかない（緑の上着、白い服）。
- 背の高さと頭の形が全員同じ。
- ほぼ同じ向きで、格子のように並んでいる。
- 2〜4人の組がなく、1人ずつ同じ間隔で立っている。

本物のクラブの、混み合った感じにしてください。

### 置き方
- 格子に見えない並べ方にする。例：最低距離を守ってランダムに置く。
- ダンスフロアは、DJブースに近いほど密にする。端はまばらにする。
- 半分くらいは、2〜4人の組にする。組の中では、お互いを向くか、半円になる。
- 向きは「DJブースを向く」「組の相手を向く」「バラバラ」を混ぜる。
- バーはカウンターに向かう人と、背を向けてもたれる人を混ぜる。ラウンジは座る人を入れる。

### 姿勢
- 少なくとも6種類にする。
  - 踊る（2〜3種類）。
  - 片手を上げる。
  - グラスを持って立つ。
  - 話す。
  - スマホを見る。
  - もたれる。
  - 座る。
- 今の「腕を前に出した形」が、意図した姿勢か確かめる。違うなら直す。

### 服と体
- ホテルの客のGLBにある服を、できるだけ多く使う。色が2種類に見えないこと。
- 背の高さを、1人ずつ少し変える（±5%程度）。
- 姿勢と服の組み合わせを増やしても、同じ形をまとめて描くこと（インスタンス描画）は続ける。

### 動き
- 揺れ方を、姿勢ごとに変える。
  - 踊る人：上下に弾む、体をひねる。
  - 立ち話の人：小さく体重を移す。
- 3人以上が同じ時刻に同じ動きをしない決まりは、そのまま守る。

### 守ること
- 性能：第2.5段階の報告と同じ測り方で並べる。群衆60人で、第2段階より重くしない。
- 置き場所の決まり（通り道を1m以上空ける、職員の区域・扉・階段に置かない）は変えない。
- 写真：入口から見たフロア、ダンスフロアの中、バー、VIP席から見下ろしたフロア。直す前と直した後を並べる。

## 3. 記録の不具合

`20261103-140913_club-full.json` では、次のことが起きています。

- `sight` 428行の `people` が全部空。ゲーム側の `watchers` は72回0より大きく、`player.spotted` も49回出ている。
- `draw` 18回の非反応の理由が、ほぼ全部 `outside_cone` だった（245件）。
  - 3.8m先の客も、壁の向こうの客も `outside_cone` になっている。
  - `solid`、`distance`、`crowd` が一度も出ていない。
  - 5.7m先の `guest_15` は `outside_cone` と書かれたのに、0.4秒後に `gun_drawn` で通報している。
- そのため、群衆が視線をさえぎった回数（`blocked`）も、ずっと0になっている。

`ClubTrace.sight()` から `perceive(..., inspect)` を呼んだときの判定が、ゲーム本体の判定と食い違っています。

- 原因を見つけて直す。
- 疑わしい所：`PlayerView` の `y` や `floor`、向き（`heading`）、`vision()` の値が、本体と同じか。`dy` が NaN になると `outside_cone` に落ちる。
- 試験を足す。
  - 前に立つ人：`sight`。
  - 背中側の人：`outside_cone`。
  - 壁の向こうの人：`solid`。
  - 遠い人：`distance`。
  - 群衆の向こうの人：`crowd`。
- 直したら、短く遊んだ記録で `sight.people` と `blocked` に中身が入ることを確かめる。
  - 試しの記録には `meta.test` を付ける。
  - 報告したら消す。人の記録は消さない。
