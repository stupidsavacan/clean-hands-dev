# クラブ第3段階

## ドロップのボタン

- DJの場内案内はフロア全域で字幕が出る。機材室の近くでは、技術係の独り言から配線を知る。
- 投資家は正面階段を下り、12:00と24:00にDJブースのボタンを押す。護衛は従来どおり付き添う。
- 技術係の服を取って機材室から操作する経路と、キャットウォークからはしごで下りて操作する経路を、本番の判定で通した。
- 12:00は準備なしで無事故だった。24:00は配線を外してフロアに戻る手順で通した。投資家は感電し、事故とチャンス達成が各1件加算された。
- 照明卓を操作すると、ドロップでフロアの照明と床の光が8秒消える。その間、フロアの人物は視野の距離と疑いの増え方が45%になる。群衆の視野距離も45%になる。

## 裏の密会

- 厨房の立ち話か、事務所の机のメモで発見できる。予定では17:00から移動を始め、18:00ごろに搬入口へ出る。
- 内線は**店長と用心棒の服**で使える。両方とも事務所へ入れる。店長は来客を取り次ぎ、用心棒は到着を知らせる役目が自然なので選んだ。
- 内線は18:00より前に1回。約60秒後に到着する。通常の密会予定の方が早い時は、そちらの時刻を優先する。12:00の催しと呼び出しが重なれば、呼び出しを優先する。
- 警戒度2以上、投資家が通常行動以外、または別の動作中なら呼べない。移動中に同じ条件になった場合も、到着前に中止する。通常の予定も、出発時と移動中に同じ条件を見る。
- 定刻でも内線でも、随行護衛は厨房の入口（x=5.15、z=30.70）に残る。搬入口を使う皿洗いは密会中だけ厨房で作業する。密会終了後は通常の予定へ戻る。
- 短いブラウザ確認では内線から59.7秒で到着した。単体試験では店長の服を取り、メモ、内線、背後からの排除、運搬、冷凍庫への収納まで通した。

## 確認とプレイテスト

- 追加した7件は、準備なし、感電と得点、消灯、配線への2経路、内線と収納、定刻、警戒時を確認する。
- `npm test` はホテルと夜会を含む321件が成功。ゴーストの通し試験は `[Ww]alking ghost` を指定して除外した。`npm run check` とクラブの単体HTMLの生成も成功。[試験結果](club-stage3-tests.txt)
- 地面、区域、開口、壁、家具の衝突、階段、検査線と基本予定を第2.5段階のデータと比較した。すべて一致した。
- 記録に `chance.updated` と `flag.set` が入る。発見、準備、呼び出し、到着、感電の時刻とプレイヤー位置を追える。ブラウザ確認の記録は `meta.test=crowd-qa` を付けてメモリー上で確認した。ブラウザエラーは0件。[ブラウザの確認結果](club-stage3-browser.json)
- フロアから配線と照明を試し、ドロップのどこが自分の操作で変わったかを説明できるか確かめてほしい。
- 内線を使った後、自分で投資家の予定を変えたと感じられるか。厨房に残った護衛と、搬入口に来た投資家の違いが伝わるか確かめてほしい。

## 性能

第2.5段階と同じ方法で、表示ありのChrome 156、1440×765、端末の表示倍率2で測った。実際の3D描画は2160×1147。表通りとフロアで視点を固定し、各2秒の準備後に16秒測った。ビルド、試験、撮影は測定と分けた。既に開いていた別のChromeは起動したまま。

|第3段階の最終ビルド|64.2 / 60.9 FPS|74.9 / 73.2 FPS|
