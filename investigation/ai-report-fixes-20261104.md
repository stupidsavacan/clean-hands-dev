### 検問とコイン（貼られた仕様）

| 仕様 | 実装 |
|---|---|
| 1. 検問担当は持ち場を優先 | 入口の2人（`gate_frisk`・`gate_watch`）は持ち場を持つ（前からあった） |
| 2. 「振り向く」と「見に行く」を分ける | 持ち場の警備が見に行くのは、持ち場が空かないときだけ。それ以外は振り向くだけ。振り向いた人の次に近い人が、見に行くことはある |
| ・プレイヤーが検問から離れている | 10m以上離れていれば（`rules.noise.postLeave`、既定10）、担当も見に行く |
| 3. 重大な事件はコインより優先 | 無線・通報・落ちた銃の回収では、今までどおり持ち場を離れる |
| 4. 担当がいなければ身体検査なし | 担当が見に行っている間は、検査なしで線を越えられる。区域の立入権限は別に判定する（前からの仕組み） |
| 5. 2人組は残りの人数で変える | 相方は、担当が持ち場にいれば見に行ける。身体検査をする担当は、プレイヤーが近くにいる間は離れない。最後の1人は振り向くだけ |
| 投げる瞬間を見られた | 音を聞くはずの人がプレイヤーを見ていたら、コインではなく投げた人を怪しむ（「振り向く」段階）。画面に「投げるところを見られた」と出る |

場所：`ai.ts` の `noise`・`mayLeavePost`・`sawThrow`、`engine/weapons.ts`（持ち場の位置と担当の印）、`engine/game.ts`（コインの表示）。
