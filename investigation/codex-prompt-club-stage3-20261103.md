## 1. ドロップのボタン（設計書5.1）

**筋書き**
- 投資家は、ゲーム内の12:00と24:00の2回、正面階段を下りてDJブースに上がり、ドロップのボタンを押す。
- 護衛の付き方は、今の予定の決まりに合わせる。

**気づき方**
- DJのマイクの案内は、フロアのどこでも聞こえる。誰でも気づける。
- 技術係の独り言は、機材室の近くで聞ける。これで手順が分かる。
- 文の中身は設計書のとおり。

**準備**
- 機材室でボタンの配線を外す。
  - 技術係の服で入るか、キャットウォーク経由で入る。
  - どちらの道でも準備できることを確かめる。
- 投資家がボタンを押すと感電する。**事故**として扱い、事故の得点に数える。
- 照明卓を触ると、ドロップの瞬間に照明が落ちる。
  - 落ちている間は、フロアの人物と群衆の視線を弱める。
  - 弱める量と長さは、データで変えられるようにする。

**守ること**
- 準備をしていなければ、何も起きない。ボタンを押すと、ただ曲が盛り上がるだけ。
- 2回目（24:00）でも成り立つようにする。1回目を逃しても遊べる。

## 2. 裏の密会と内線の呼び出し（設計書5.2）

**筋書き**
- 投資家は、18:00に厨房を通って搬入口へ出る。
- 護衛は厨房の入口で待つ。搬入口では投資家が一人になる。

**気づき方**
- ボトル係と料理人の立ち話。
- 事務所の机のメモ。

**呼び出し**
- 事務所の内線電話で「相手が早く着いた」と伝えると、投資家は約1分で裏へ来る。
- 内線を使える服を決めて、データに書く（例：店長か用心棒の服、または事務所に一人でいる時）。決めた理由を報告に書く。
- 呼び出しは1回だけ。18:00を過ぎたら使えない。

**実行**
- 搬入口で一人になった投資家を倒し、ごみ箱か冷凍庫に隠せる。夜会の隠し場所の仕組みを使う。
- 搬入用のリフトの事故は作らない。

**守ること**
- 呼び出したときも、18:00の予定どおりのときも、護衛は厨房の入口で待つ。
- 投資家が騒ぎや警戒の中にいるときは、裏へ来ない。いつ来なくなるかを報告に書く。

## 3. 自由な手段（設計書5.3）

新しく作るものではありません。今の仕組みで成り立つかを確かめて、報告に書いてください。
- VIP席のボトルに毒。ボトル係の服で裏階段から運ぶ。
- 投資家がトイレで一人になる時間。予定にトイレがなければ、1回足してよい。
- コインで護衛を1人ずらし、キャットウォークからVIP席へ入る。

成り立たないものがあれば、理由を書いてください。直すのは、小さな直し（予定の時刻、物の位置）で済む場合だけにしてください。

## 4. 難易度をあとで調整しやすくする

人がこの段階を遊んだあとで、難易度を調整します。そのための下準備だけしてください。値は変えません。

- 難易度に効く値を、1つの一覧にまとめて報告に書く。値が今どのファイルにあるかも書く。
  - 警備の人数と持ち場。
  - 視野の距離と角度、疑いがたまる速さ。
  - 群衆の人数、目撃のオンとオフ、視線のさえぎり。
  - 検査、チャンスの時刻、呼び出しのタイミング。
- ハードコードされていて、データで変えられない値があれば、クラブ用のデータへ移す。
  - ホテルと夜会の動きは変えないこと。
- プレイテストの記録に、チャンスの進み具合を足す。
  - 例：気づいた、準備した、呼び出した、標的が来た、事故が起きた。
  - 時刻とプレイヤーの位置も一緒に残す。

## 合格の目安
- `npm test` と `npm run check` が通る。ホテルと夜会の試験も落ちない。
- 単体の試験を足す。
  - 準備ありでボタンを押すと事故になり、準備なしでは何も起きない。
  - 照明を落とすと視線が弱まる。
  - 呼び出しで投資家が約1分で裏へ来て、護衛は厨房の入口で待つ。
  - 呼び出しは1回だけ。
  - 警戒の中では裏へ来ない。
- 各チャンスを、試験の中で最初から最後まで1回ずつ通す。ブラウザでの長い通し試験はしない。
- 性能が、第2.5段階の再修正（`club-crowd-fix2-report-20261103.md` の測り方）より悪くならない。

## してほしくないこと
- 第4段階に進まない。
- ゴーストの通し試験をしない。
- 難易度の値を変えない（一覧にまとめるだけ）。
- 平面を変えない。群衆の場所の数値を変えない。
- ホテルと夜会のゲームの動きを変えない。
- git commit / push をしない。公開をしない。
- 人の記録を消さない。試しの記録には `meta.test` を付け、報告したら消す。
