## 段階4でやること

前の依頼文の「段階4　服装ラボを作り直す」を行います。次の点を足します。

### 1. 新しいキャラの作り方

服装ラボで、次の順に進めて新しいキャラを作れるようにします。

1. 体型を選ぶ（レシピにある体型：キャストの男性・女性、プール客の体型など）。
2. 頭・顔・髪を選ぶ。
3. 部品を順に選ぶ（トップス → パンツ → 上着 → 靴 → 小物 → 模様）。その体型に合わない部品は選べないようにします。
4. 色を選ぶ。肌・髪・靴まで一度に塗り替えないよう、色は部品の役割ごとに選びます（段階1の報告のとおり）。
5. マーク（文字・PNG）を置く。今の機能を残します。
6. 「保存して作る」で、レシピを保存し、Blender で GLB を作り、できた GLB をラボで表示する。
7. できた GLB で、歩き・しゃがみ・ダンス・仕事を再生して確かめられる（アニメーションラボと同じ動きを使う）。

- 新しいキャラのレシピは、既存の38個と分けて置きます（例：`assets/characters/recipes/new/`）。既存のレシピは、ラボから書き換えられないようにします。
- 「既存キャラを開く」で38個のどれでも開けて、その部品から組んだ姿と、元と同じかどうか（段階3の結果）が見えるようにします。

### 2. 8795 のサーバーで Blender を動かす所

### 3. 今の上着の部品（agent07-jacket）

- 今の服装ラボの上着（フィールドジャケット・フライトジャケット・ブレザー、襟・丈）は、リポジトリの外の `outputs/agent07-jacket/` から作られています。
- 新しい部品庫に入れられる物は入れ、元のファイルは `assets/outfits/agent07-jacket/`（または `assets/characters/` の中の決めた所）に写して、リポジトリから作り直せるようにします。元の `outputs/agent07-jacket/` は消しません。
- 入れられない物は、理由を報告に書きます。

### 4. 画面

- 服装ラボは開発用のラボなので、ゲームの画面の決まり（UI ラボで仕上げてから）はかかりません。ただし、今のラボと同じ見た目の決まり（色・文字・並べ方）に合わせます。
- 1080×810 と 1920×1080 で、はみ出し・重なり・切れがないことを確かめ、画像を残します。

### 5. 確かめること

- 新しいキャラを1人、ラボの操作だけで作り（例：「バーの常連客」）、GLB ができて、歩き・ダンスで服が破れないことを、画像で示します。
