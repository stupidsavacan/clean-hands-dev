# Codex への依頼：パーティー会場の試作（作業2へ進む）

`codex-prompt-party-prototype-20261101.md` の続きです。作業1の設計（`party-design.md`）を確認しました。**このまま作業2（実装）まで進めてください。途中で止まる必要はありません。** ただし、作業2の最初に、下の「直してから作ること」を設計に反映してください。

## 設計の良いところ（このまま残す）

- 19区域・36接続で、行き止まりがありません。
- スタッフの階段だけで、全4階を行き来できます。
- 舞台の3区域それぞれに、3通り以上の入り方があります。
- 主人の30分が、外周 → 客の環 → 個人の核 → 客の環と、層をまたいで動きます。
- 顔を知る人を、通路のただ一つの出口に置かない方針です。

## 直してから作ること

### 1. 正門の検問が、意味を持たない

- **問題**：正門前 V から庭 G へ、何も要らずに行けます（接続02）。庭から舞踏室へも、何も要りません（接続04）。そのため、身体検査（接続01）を受けずに、銃や毒を持ったまま、表の客の場所すべてに入れます。検問を避ける道が、検問を通る道より楽です。
- **直し方**
  - 外から館の敷地へ入る道は、どれも何かを払うようにしてください。
    - 正門：身体検査（今のまま）
    - 使用人の入口（中庭 C 側の外）：スタッフの服
    - 塀を越える抜け道：人目を避ける必要がある
  - 庭 G は、検問の内側（玄関ホール H か舞踏室 B から出る場所）にしてください。
  - 検問を避ける入り方が2つ以上ある、という基準は保ってください。ただし、どれも「服」か「抜け道と見張り」で払う形にします。

### 2. 清掃員の服が、合鍵になっている

- **問題**：清掃員の服は、公共・スタッフ区域に加えて、区域例外で客室 Q・書斎 O・主寝室 M にも入れます。この1着で、ほぼ全部の場所へ行けます。
- **直し方**
  - 清掃員の区域例外は、客室 Q だけにしてください。
  - 書斎 O と主寝室 M に正面から入るのは、護衛の服にしてください（顔を知る護衛隊長がいる）。
  - 書斎と主寝室へは、ほかに「抜け道」と「裏の通路 U からの護衛の服」で入れるので、入り方の数は減りません。
  - 設計の表の「入れる服」を、この決まりに合わせて書き直してください。

### 3. 部屋と部屋のあいだの窓は、外の縁に置き換える

- **問題**：客室 Q ↔ 書斎 O（36）、客室 Q ↔ 主寝室 M（31）が、屋内の部屋どうしの「窓」になっています。家の作りとして不自然です。また、Q と M は隣り合っていない位置に描かれていて、つながりが成り立ちません。
- **直し方**
  - 2階の Q・O・M の外側に、**外の縁（バルコニーの手すりの外を伝う足場）を1本**通してください。
  - 各部屋の窓から、その縁へ出入りできるようにします。
  - 庭からの雨どい（22）や、屋根からの雨どい（34）も、その縁につなげてかまいません。
  - こうすると「外から回り込む層」が1本でき、かたつむりの形にも合います。

### 4. チャンス2「書斎の書類」の倒し方が、決まっていない

- **問題**：「書類を差し替えて主人を机に誘導し、近くで排除」は、最後がただの手での排除です。チャンスとして、何が起きて、どう倒すのかがはっきりしません。
- **直し方**：最後を、はっきりした仕掛けにしてください。例：
  - 机が窓の前にあり、差し替えた書類を読みに主人が窓の縁へ出る → 3の外の縁から突き落とす（事故）
  - そのほか、このマップで初めての倒し方
  - チャンス1（シャンデリア）はホテルのB1と同じ仕組みです。今回は場所の作りを試すのが目的なので、そのままでかまいません。

### 5. 図を、縮尺のある平面図にする

- **問題**：今の平面図の下書きは、区域を同じ大きさの箱で並べたもので、位置関係がありません。マップの良し悪し（どこから何が見えるか、どの順に巻いているか、どれくらい歩くか）は、実際の配置で決まります。
- **直し方**
  - 作業2の最初に、座標を決めた階ごとの平面図（縮尺あり。壁・開口・階段・抜け道の両端・家具・隠し場所・検問・見張りの位置）を作ってください。
  - その平面図で、設計の表（区域・接続・合格の基準）を測り直してください。

### 6. つながりの測り方を、階段と抜け道まで広げる

- `map-topology.ts` は、今は同じ階の歩ける格子の境目だけを数えています。
- 階段と抜け道も接続として数え、設計の36接続と一致するかを、実装したマップで確かめてください。
- 一致しない接続があれば、表にして報告してください。
