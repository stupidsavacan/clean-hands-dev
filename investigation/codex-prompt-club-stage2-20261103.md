## 第2段階の中身

### 1. 人（34人）
- 内訳は設計書4.2。警備は調べものの案（5人：入口2、巡回1、VIP階段1、投資家の護衛1）で始める。
- モデルは設計書4.2の通り。ホテルの客のモデルを使う。`guest_male` はGLBがないので使わない。
- 投資家は `investor`。今回は予定どおりに動くだけ。チャンスの台本はまだ入れない。

### 2. 予定：塊にしない（いちばん大事）
- 夜会では、客が組ごとに同じ時刻に動いて不気味だった。クラブでは同じ失敗をしない。
- 客は1人か2人ずつ、「行き先の候補」と「いる時間の幅」を持つ。次の行き先と時間は、人ごとに決まった乱数で選ぶ（設計書4.1）。
  - 行き先：フロア、バー、ラウンジ、トイレ、喫煙所。
  - 毎回同じ予定になるようにして、試験できるようにする。
- 3人以上が同じ時刻に同じ動きをしないこと。数値で確かめて報告する。
- ダンスフロアに人が集まるのはよい。ただし、立つ位置と向きは1人ずつずらす。
- 職員は持ち場で働く。
  - バーテンダー：カウンター内とバー倉庫。
  - ボトル係：厨房 → 裏階段 → VIP席。
  - 料理人・皿洗い：厨房、皿洗いは裏路地のごみ出しも。
  - 技術係：機材室、DJブース、キャットウォーク。
  - 店長：事務所とバー。
- 職員の持ち場は、その服で入ってよい区域にする。持ち場で侵入者扱いにならないことを確かめる。

### 3. 服と検査
- 服の取得は設計書6章。収納や着替えの仕組みは、夜会のものを使う。
- 入口の用心棒が客を検査する。銃は通さない。ワイヤー・毒・コインは通る。
- 銃は事務所の金庫に1丁だけ置く。

### 4. 増援なし（クラブだけ）
- 調べものの「ゲーム側の変更案」の通りにする。
  - クラブ専用の戦闘設定で、増援を出さない。
  - 警戒度3でも人が増えない。倒れた警備は戻らない。
  - 近い警備は現場へ向かい、残りは持ち場を守る。最後に見られてから時間がたったら、持ち場へ戻る。
- **ホテルと夜会の増援は変えないでください。** 共通の部品を直すときは、ホテルと夜会の試験が通ることを確かめてください。
- この部分には単体の試験を足してください（人が増えない、復活しない、持ち場と応援の両方が動く）。

### 5. 小さな直し
- 画面上部で、区域名（「1F 入口・クローク」）と時刻（「探索 00:05」）の文字が重なっている。クラブの画面で直す。
- ブラウザのタブ名が「M5 ホテル」のまま。クラブの名前にする。
