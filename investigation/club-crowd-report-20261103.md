# クラブ第2.5段階　群衆とプレイテスト

## 作ったもの

- 従来の34人に、フロア40人、バー12人、ラウンジ8人の群衆を追加した。
- 既存の客モデルから服の色と姿勢を焼き込んだ。同じ形はまとめて描画する。揺れの速さと位相は個別。
- 群衆は予定と疑惑ゲージを持たない。密な場所では視線が遮られ、混ざると見つかりにくくなる。プレイヤーは混んだ場所で減速する。通常の人物は通り抜けられる。
- 銃声、近くで見た銃、殺しに反応する。悲鳴を上げて散開し、しゃがんだあと元の位置に戻る。警備に知らせるのは騒ぎの位置。殺しの目撃をゴーストに反映する設定は初期値でオン。
- 群衆の場所は `build-club-source.py` から生成する。人数、中心、範囲、向き、姿勢を編集できる。`?crowd=120` は倍の人数を試す設定。
- 通行が多い箇所は第2段階の30分の移動を0.1秒ごとに記録して抽出した。0.25m格子で15サンプル以上の箇所から、群衆の中心を0.83m以上離した。すべての迂回経路を専用通路にしたわけではない。

## 記録と分析

- `foot` は0.5秒ごとの位置、階、区域、服、姿勢、手に持つ物、銃、行動、群衆に混ざったか。
- `sight` は1秒ごとの人物の視線、見える群衆の人数と場所番号、遮った群衆の場所番号。
- `action` は行動の開始と終了。`reaction` は反応と理由、視覚か音か、距離。`draw` は銃を出した瞬間の周囲20mの人物の反応と非反応。
- 試験記録 `20261103-140835_club-full.json` の0.13秒で、巡回の用心棒が7.81m先の群衆の悲鳴を聞いて調べに向かった。反応の理由は `crowd_scream`、感覚は `sound`。
- 30分相当の合成データ約1.45MBを送信した。終了時の追記を含む5,521行が保存された。短いブラウザ試験の記録には `meta.test: crowd-qa` を付けた。

`playtest` で `node analyze-crowd.mjs` を実行する。個別の記録はパスを引数に並べる。

```powershell
node analyze-crowd.mjs runs/20261103-140835_club-full.json
```

[分析図](../playtest/runs/crowd-analysis.svg)と[集計JSON](../playtest/runs/crowd-analysis.json)を出力した。試験では、フロアのC1・C2・C3から銃を出した行動が各1回見え、「注意」になった。バーとラウンジは「記録なし」。この試験では遮蔽の実例は0回だった。分類は記録に基づく目安で、遊びやすさの最終判定は人が行う。
