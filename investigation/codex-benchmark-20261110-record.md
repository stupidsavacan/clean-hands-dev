## 判断の参考（結果が出たら埋める）

結果：7件すべて合格。追加の依頼は1回で済み、2回目は使わなかった。決まり違反は軽いもの1件だけ（未追跡の生成ファイル・見出しの残り）。追加1回目は3分ほどで済んだ。spec はどちらの回も Claude が回して同じ結果だった。

- **Codex に任せてよい作業**：
  - 調査（再現しないことを、正直に再現しないと言える）
  - 道具・コマンドの機能追加
  - 仕様を試験にする作業
  - AI ラボの場面
  - UI ラボの案
  - モデルや動きも、数字で書ける部分なら任せてよい
- **任せる時に、依頼文に書き足すべきこと**：
  - 見た目の作業では、数字だけでなく見た目の要件を書く。例：「丸く見える」「手は胸の高さ」「体重は後ろ」「腰は離れる向き」。
  - 数字だけだと、数字を満たしたまま見た目が不自然になる（1回目の4・5）。
  - 三角形の上限など、形を縛る数字は、見た目を損なわない値にする。
  - 「できたら」の行を、そのまま確かめられる形で書く。今回は、それで自己申告と実際が一致した。
- **任せない方がよい作業**：今回の範囲では見つからなかった。見た目の最終判断（利用者の好み）だけは、利用者か Claude が画像で見る。
- **追加の依頼で直りやすかった所**：
  - 数字で言い直せる見た目の直し（断面の角数、手の高さ、腰の向き）は1回で直った。
- **気をつける所**：
  - Codex は作業を並べて速く進めるので、依頼の前提が間違っていると、そのまま速く進む。
  - 依頼文の前提（今回の作業1の答え）は、Claude が先に確かめておく。

**結論**：

- この2つでは、**1回目の見た目は Claude の方が上**だった。
  - Codex が追加の依頼で直した2点（棒に見えない・手が顔の高さで体が扉へ寄る）は、Claude では1回目から起きていなかった。
  - Claude は画像を見て自分で直していた（砂色→木の色、頭を隙間へ向ける、足の沈み、肘の逆向き）。
- ただし差は「追加の依頼1回分」。Codex も数字で言い直せば3分ほどで直った。
- Claude の方が遅かった（2件で26分）。
- 1回の比べで、作業も2つだけなので、決めつけない。

**割り振りへの使い方**：

- 見た目が大事で、見た目を数字で書き切れない作業（モデル・動き）は、Claude がやるか、Claude が1回目の画像を見て直しを数字で書く。
- 見た目を数字で書ける作業や、それ以外の作業（調査・道具・試験・AI 場面）は、これまで通り Codex に任せてよい。
