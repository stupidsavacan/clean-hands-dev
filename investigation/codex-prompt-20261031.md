## 作業2：全チャンスでゴーストを可能にする

作業1のあとで `ghost-sim.ts` を流し直し、まだゴーストできないものだけを直す。目標は、**14チャンスすべてで、正しくやればゴーストで終われること**（素手のXはこの目標に含めない）。

各チャンスで、まず下の「案」の中から一番小さな変更を選ぶ。どの案も合わないときは、理由を書いて止まる。チャンスの筋書き（何をすると、どう死ぬか）は変えない。

| チャンス | いま崩れる理由（修正前） | 直し方の案 |
|---|---|---|
| A3 プールの照明 | 作動場所が人から丸見えで、殺人扱いになる | 作業1の③で直る見込み。直らなければ、作動を配電盤側（人目のない所）からの遠隔にする |
| A5 展示ヨットのクレーン | 操作盤が客・警備・`CAM_marina` から見える | ①③で直る見込み。直らなければ、操作盤の位置をカメラと人目から外す |
| B2 試食会（ガス） | 爆発範囲にBの私設護衛3人が入る | 試食の間、護衛は離れて立つ（B1のスピーチと同じ扱い）。範囲・立ち位置は JSON で決める |
| C5 浜辺の花火 | 範囲に浜辺の客4人が入る | 花火が当たるのを投資家の席だけにする。または客の位置をずらす |
| A4 テラスの記念撮影 | 押す瞬間を警備・ウェイター・客に見られる。カメラマンの服もバレる | 撮影の台本として、警備と周りの客が手すりから離れる・背を向ける時間を作る |
| C3 屋上のヘリ | ヘリポートの警備が縁の正面にいる | 出迎えの間、警備が持ち場を離れる（ヘリの点検に行く等）台本を足す |
| C4 出張マッサージ師 | 手を下した殺しなので必ず殺人で、死体を隠す場所がない | ペントハウスに隠し場所（`hotel.json` の `hides`）を1つ足す。`scripts/build-hotel.ts` で生成し、`hotel.json` は手で書き換えない |
| B3 護衛の交代 | 付き添うと、ほかの護衛3人も付いてきて、倒す瞬間を見られる | 付き添い中はほかの護衛を元の位置で待機させる。人のいない場所（客室・裏の通路など）まで誘導できるようにする |

ゴーストできる正しい手順を、チャンスごとにテストにする（`tests/ghost.test.ts` など）。
- テストでは、周りの人を消さない（既存の M5.7 テストのように `clearAround` しない）。
- 作動場所へは、ほかのテストと同じく瞬間移動で立ってよい。
- 採点は `ScoreLedger` と `computeResult` を使い、`ghost === true` を確かめる。
- 巻き込みがなくなったこと（標的以外の死者が0人）も確かめる。
