# クラブ第2.5段階の修正

## 群衆

- メモ1（136.2秒）では、白と緑の服、同じ腕の曲げ方、同じ向きが繰り返されていた。旧実装では踊る人の服が2モデルで、腕の形も共通だった。
- 6つの既存モデルから服と頭を使った。身長の倍率は0.952〜1.044。体幅と向きも分けた。
- 姿勢は8種類。跳ねて踊る8人、体をひねって踊る7人、片手を上げる2人、グラス22人、立ち話14人、スマホ2人、もたれる3人、座る2人。
- 座る2人はラウンジの既存の西ソファを使う。配置の中心と広さ、各場所の人数は従来どおり。
- 60人のうち29人を11組にした。各組は2〜4人で、お互いに向く。ほかの人はDJ台やカウンターを向くか、個別に向きを選ぶ。
- 位置を連続値で抽選した。フロアではDJ台側を多めに抽選した。通行帯から0.83m以上を保つ条件、階段・家具の除外条件は維持した。
- 踊りは上下の弾みとひねり。会話は小さな重心移動。位相と速さは各人で違う。姿勢と服が同じ人はまとめて描画する。

## 視線記録

- 人の記録では `sight.people` が428行すべて空だった。前回の検証では保存と分析の出力を確認したが、可視人物と遮蔽が記録に入る確認が抜けていた。
- `playtest/debug.js` の `P.perceive` は、F9を開く前から視線判定を包んでいる。旧コードは引数を3つに固定し、`ClubTrace.sight()` が渡した第4引数を落としていた。記録用の結果は初期値のままだった。
- 全引数を本体へ転送するよう直した。正面、背面、壁、距離、群衆の5条件で、記録用と本体の可視率が一致することを試験した。
- 試験 `20261103-142448_club-full.json` は `meta.test: crowd-qa`。フロアの試験開始位置（24, 22）から歩いた。最初の0.02秒に `people` はDJ（10.30m、可視率1）を記録した。同じ行の `blocked` は `guest_01` と `guest_03` の視線を遮った場所が `C2` だと記録した。
