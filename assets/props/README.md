# 仕草の小物と立ち机

2026-11-05。Claude が作った。予定の仕草（`app/src/gestures.ts`）で使う。

- 作り方：`blender -b -P source/build_props.py`（全部）。名前を付けると1つだけ（例：`-- desk_pc`）。
- 決まりは持ち物（`../items`）と銃（`../m55-combat`）と同じ：16色パレット、平らな面、roughness 1、1つ1GLB、メートル。
- 手に持つ物：握る点が原点（`GRIP_R`）、長い向きが +Z。手の中での向きは `gestures.ts` の `PROP_POSE` が、人の向き（上・前）で決める。
- 検証：`node source/validate.cjs`（Khronos glTF Validator。全部エラー0・警告0）。
- ゲームへの埋め込み：`app/scripts/embed-props.mjs` → `app/src/prop-data.ts`。読み込みは持ち物と一緒（`app/src/item-models.ts`）。

desk_pc：原点は机の手前の縁の真ん中の床。+Z が机の奥。天板は 0.95m（立ち机）。机に向かう人の右（-X）にマウス、左に書類と PC 本体。キーボードは縁から 0.14m。

boombox：原点は置く面の上、本体の真ん中の下。+Z が前（スピーカー側）。高さ 0.561m はアンテナの先まで（本体は 0.24m）。

moving_head は吊り金具の上面中央をモデルの原点 `HANG` とする。glTF では `base` の下で `yoke` が +Y 軸でパンし、その下で `head` が +X 軸でチルトする。静止姿勢のレンズは真下（−Y）を向き、レンズ中央の `BEAM` が光の出る点。両アンカーはそれぞれ `base` と `head` に属する。

dj_desk はステージ床の卓中央が原点。+Y が上、−Z が客席側、+Z が DJ 側。ノートパソコンの画面は DJ 側を向く。ミキサーの後端だけ DJ 側へ張り出し、手を置く縁の高さはステージ床から 0.927 m。 ノートパソコンは DJ の右の一段低い棚（0.70 m）にスタンドごと置く（Claude 版の卓から移した。2026-11-10）。
