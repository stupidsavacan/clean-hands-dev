# 持ち物のモデル（道具・近接武器・投げる物）

2026-11-05。Claude が作った。

- 作り方：`blender -b -P source/build_items.py`（全部）、`-- hammer` のように名前を付けると1つだけ。
- 決まりは M5.5 の銃と同じ：同じ16色パレット、平らな面、roughness 1、1つ1GLB、メートル。部品の作り方の関数も銃のもの（`../m55-combat/source/build_m55_assets.py`）を使う。
- 向き：手で握る点が原点（`GRIP_R`）。柄は +Z に伸び、頭・刃・口が +Z の先にある。`TIP` は先端。
- 検証：`node source/validate.cjs`（Khronos glTF Validator。全部エラー0・警告0）。
- ゲームへの埋め込み：`app/scripts/embed-items.mjs` → `app/src/item-data.ts`。
- 確かめ方：持ち物ラボ（`http://127.0.0.1:8795/item-lab`）の「すべて自動判定」。
