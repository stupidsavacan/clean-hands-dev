# 動きを直してもらう時の頼み方（ほかの AI に渡す用）

2026-11-07 作成。下の「依頼文のひな形」を埋めて、このファイルごと渡します。前半は、依頼する人が書く所です。後半は、AI が守る決まりです。

## 依頼する人が書くこと

| 項目 | 書くこと | 例 |
|---|---|---|
| どの動きか | 名前、または場面 | 刀で正面から斬る（M14）、素手の格闘（M02）、ブリーフケースを持って歩く |
| どこで見たか | ラボの動きの名前、またはゲームでの出し方 | アニメーションラボの「pair-katana-front」／クラブの VIP 席で刀を拾い、警備の正面で X |
| 今の何がおかしいか | 見た目で。画像があれば付ける。何秒目かも | 振りかぶりが小さく、腕だけで振っている。0.4 秒目に刃が相手の肩をすり抜ける |
| どうしてほしいか | 段階ごとに。構え → 踏み込み → 当たる → 戻る | 右足を半歩出しながら両手で頭の上まで振りかぶり、左上から右下へ斬り下ろす |
| 手本 | 実際の動きの説明、動画の場所と秒数 | 剣道の面ではなく、居合の袈裟斬り。動画の 0:12〜0:15 |
| 受ける側 | 相手がどう崩れるか | 斬られた側の肩から後ろへよろけ、膝から落ちる |
| 速さ | 全体の長さ、当たる瞬間 | 全体 1.0 秒、当たるのは 0.5 秒目（今と同じでよい） |
| 変えてほしくない所 | ほかの動き、長さ、操作 | 背後からの突き（M15）は今のまま。押すキーは X のまま |

迷った所は「分からない」と書いてかまいません。AI が案を2つ出し、ラボの画像で選べるようにします。

## AI が守る決まり

### 読むもの

- `CLAUDE.md` と `docs/DEVELOPMENT.md`（「動き（モーション）を直す」の節）。
- 資料の決まり（`app/tests/item-spec.test.ts` と、そこが引く S03・S08・S09 の行）。HITMAN に合わせる話なら `docs/HITMAN-ALIGNMENT.md` も読む。

### どこにあるか

| 動き | ファイル |
|---|---|
| 素手の格闘（顔・腹・顔）、正面の一撃 | `app/src/brawl-motion.ts`（する側 G_…、受ける側 R_…） |
| 刀：正面の袈裟斬り・背後の突き | `app/src/katana-motion.ts`（FRONT・BEHIND・FRONT_HIT・BEHIND_HIT）、刀の向きと左手は `app/src/katana-pose.ts` |
| 物を持った時の腕・鈍器や包丁で殴る・刺す | `app/src/hold-pose.ts`（strikePose） |
| 変装・検査 | `app/src/m4-motion.ts` |
| 歩く・走る・しゃがむ | `app/src/locomotion.ts` |
| 背後からの拘束・運ぶ | `app/src/motion.ts`、`app/src/m3-view.ts` |
| 足を地面に置く、手を相手に向ける | `app/src/motion-runtime.ts`（plantFeetAt・reachHandsAt・aimFists） |
| ゲームでの組み合わせ（相手との間合い） | `app/src/m3-view.ts`（BRAWL_GAP・KATANA_GAP） |
| 確かめる所 | `app/src/labs/animation-lab.ts`（pair-brawl・pair-punch・pair-katana-front・pair-katana-back・strike-…・item-…） |

### 骨の向き

- +X がキャラクターの左です。
- 腕と脚の x は曲げです。マイナスが前です。
- y は縦の軸まわりで、プラスが左を向きます。z はひねりです。
- 足は `plantFeetAt` で地面に置きます。宙に浮かせたり、床に沈めたりしません。
- 拳や刃は、相手の骨（頭・胸）に向けます（`aimFists`）。決め打ちの高さにしません。

### 変えてはいけない物

- 頼まれていない動き。
- 遊びに関わる時間：PUNCH_SECONDS・FINISH_SECONDS・BRAWL_WINDOW（`app/src/melee.ts`）、MELEE の seconds、BRAWL_IMPACT・BRAWL_FINISH・KATANA_IMPACT。変える時は依頼に書いてある時だけです。
- 押すキー（`app/src/controls.ts`）。
- 見た目の色・モデル。HITMAN の動きをそのまま写さず、実際の武道・格闘の動きを手本にします。

### 作り方の順番

1. アニメーションラボで今の動きを見て、正面・横・当たる瞬間の画像を撮ります（直す前）。
2. キーの姿勢（keyframe）を直します。ラボとゲームは同じ関数を使うので、ラボで直せばゲームも変わります。
3. ラボで、直した後の同じ3枚を撮ります。
4. 試験：`npm run check`、`npm run test:fast`（`app/` で）。長さや当たる瞬間を変えたら、`app/tests/melee.test.ts` などの数字が合うか確かめます。
5. `npm run build:all -- club animation-lab` で作り直し、クラブで実際に出して画像を撮ります。
6. 直す前と後の画像を並べて見せ、依頼の各段階をどう直したかを1行ずつ書きます。
7. ROADMAP と作業記録を直し、コミットして GitHub（clean-hands-dev）に送ります。

### 終わりの条件

- [ ] 依頼の各段階（構え・踏み込み・当たる・戻る）が、ラボの画像で分かる。
- [ ] 足が地面から浮かず、沈まない。拳や刃が相手に届き、すり抜けない。
- [ ] 受ける側の動きも依頼どおり。
- [ ] 変えてほしくない所が変わっていない。
- [ ] `npm run check` と `npm run test:fast` が通る。
- [ ] クラブで出した画像がある。
- [ ] コミットして送った。
