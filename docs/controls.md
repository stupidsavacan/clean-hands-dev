# 操作（キーとタッチ）

このページは `app/src/controls.ts` から作っています。直接書き換えず、表を直してから `node --experimental-strip-types --no-warnings scripts/spec-docs.ts` を実行します。

新しい操作を足す時：

1. `src/controls.ts` に1行足す（空いているキーを使う。E と移動キー以外は共有しない）。
2. 持ち主のファイルでそのキーを読む。
3. タッチでも使うなら `touch` を書く（iPad のボタンはこの表から作られる）。
4. 上のコマンドでこのページを作り直し、`npm test` を通す。
