# 星見岳天文台 ― 嵐の観望会

2026-11-13 作成。ブランチ `stage/observatory`（作業ツリー `outputs/m6-observatory`）。`main` と `outputs/m5-prototype` は変えていません。

台風の夜、山上の天文台。所長（ターゲット）は後援者たちと閉じ込められています。この地図だけの仕組みは、**嵐・電気・空気が互いに影響しあい、人がそれに反応して動く**ことです。時間で起きる仕掛けはなく、人は「そこが暗い・寒い・空気が悪い・雷が落ちた」から動き、倒れます。

## 遊ぶ

1. `app/` で `npm run build:all -- observatory`（`observatory.html` ができます）。
2. `python tools/stage-server.py`（この作業ツリー専用。8795〜8798 とは別の 8806 番）。
3. http://127.0.0.1:8806/observatory.html を開く。画面が隠れていても描画を止めない版は `/raf/observatory.html`。

黄色い輪の場所で E を長押しすると操作できます。右の表示に、嵐の強さ・電源・今いる場所の明かり・気温・酸素が出ます。その下の「音」で雨・雷・発電機・警報の音が入ります。

## 世界のシミュレーション

数値はすべて `app/src/data/observatory-systems.json` にあります。

| 何 | コード | 中身 |
|---|---|---|
| 嵐 | `app/src/sim/weather.ts` | 嵐の強さの時間変化、突風、落雷の一覧（避雷針・送電線・遠方）。種が同じなら毎回同じ夜。雷鳴と雨で、音が届く距離が縮む。稲光の一瞬だけ暗がりでも見える |
| 電気 | `app/src/sim/power.ts` | 送電線 → 発電機（8秒で起動、30kW）→ 蓄電池（保安と管制だけ）。回路10本とブレーカー。発電機では重要でない回路から切る。過負荷で落ちる |
| 空気 | `app/src/sim/air.ts` | 部屋ごとの気温と酸素。扉・換気・壁・開いたドームで混ざる。暖房・薪ストーブ・電気ヒーターで暖まる。窒素が酸素を押し出す |
| 設備 | `app/src/observatory/world.ts` | 上の3つをつなぐ物。窒素の弁、酸素濃度計、検出器の冷凍機、ドームのシャッター、避雷針の接地線、電気ヒーター |

何もしない夜でも次のことが起きます（`node --experimental-strip-types --no-warnings scripts/observatory-night.ts` で一覧が出ます）。

- 6:15 送電線に落雷 → 停電 → 発電機が起動 → 暖房が切られる → 部屋が冷える → 人が談話室の薪ストーブに集まる。
- 8:11〜10:47 嵐の小康。研究員がドームのシャッターを開けて試験し、嵐が戻ると閉じる。
- 送電が戻ると、寒い部屋で一斉に入れた電気ヒーターでコンセントのブレーカーが落ち、設備技師が直しに行く。

## 人の反応

`app/src/observatory/script.ts`。

- **設備技師**：落ちたブレーカー、切られた引込開閉器、止まった発電機を、気づいてから直しに行く（1件ずつ）。倒れていれば誰も直さない。
- **所長**：検出器が温まると自分で低温実験室を見に行く（護衛は扉の外）。シャッターが雨の中で閉まらないと、キャットウォークへ出て手で回す（護衛はドームの中）。
- **寒さ**：13℃を下回った部屋の人は談話室へ。警備員は交代で短く暖まりに行く。外回りの警備員は雨がいちばん強い間、玄関のひさしに入る。
- **暗さ**：明かりの消えた部屋では人の目が利かない。保安回路まで落ちると電気錠が開く。
- **酸素**：警報が鳴れば人は部屋から出る。鳴らなければ気づかない。11%を切った部屋に数秒いると倒れ、倒れたまま30秒で死ぬ。プレイヤーも同じ空気を吸う。
- **雷**：接地線を外した避雷針に落ちると、その瞬間キャットウォークにいる人が死ぬ。

## 事故に見せる2つの道

どちらも「仕込み → 所長が自分から現場へ → 事故」で、評価は事故死になります。

1. **酸欠**：研究員が低温実験室を離れている間（4:20〜10:20）に、換気のブレーカーを切る → 酸素濃度計のケーブルを抜く → 液体窒素の弁を開ける → 冷凍機のブレーカーを切る。約1分で検出器の警報が鳴り、所長が入って倒れる。
2. **落雷**：避雷針の接地線を外す（スパナがあると早い）。小康でシャッターが開いている間にドーム駆動のブレーカーを切る。嵐が戻ると雨が吹き込み、所長が手回しに出る。2階の気象モニターで落雷の時刻が分かる（最初は 13:03）。

どちらも設備技師が直しに来るので、先に眠らせるか、ほかの故障で手を取らせます。

**二次災害は起きます。** 所長を探しに来た護衛も、同じ空気・同じ鉄骨で倒れます。弁を閉じる、接地線をつなぎ直す、で防げます。ターゲット以外の死は減点です。2026-11-13 に、このまま残すと決まりました。

## 地図を直す

- 間取り・扉・家具・人物・予定：`app/scripts/build-observatory.ts` を直して実行（`observatory-layout.json` など5つを書き出します）。`npm run map:check -- --map observatory` で検査。
- E 長押しの場所・要人警護・技師の修理：`app/src/data/observatory-mission.json`。
- 見た目（ドーム、望遠鏡、発電機、雨、稲妻、明かり、霧）：`app/src/observatory/scenery.ts`。モデルのファイルは使わず、コードで形を作っています。
- 右の表示：`app/src/observatory/panel.ts`。音：`app/src/observatory/sound.ts`。

## 確かめ方

- `app/tests/observatory.test.ts`（14件）：嵐・電気・空気の単体、地図の検査、実際のNPC AIでの通し（何もしない夜、警報で退避、酸欠、落雷、接地ありなら無事、暗さと電気錠）。
- `node --experimental-strip-types --no-warnings scripts/observatory-run.ts asphyxia|lightning|alarm|idle [秒]`：ブラウザなしで台本を流し、30秒ごとの状態を出します。
- ブラウザのコンソール：`__observatory.snapshot()`（世界と人の状態）、`__observatory.operate('ln2_valve')`（E 長押しと同じ操作）。
